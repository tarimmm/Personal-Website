# Personal-Website
After learning HTML and CSS I made my own personal website.
My idea was to create old school website like in the late 90s and early 20s.
I took inpos from neocities and some indie websites. I used glittery graphics for some stickers and background too. 
I used cursor from cursor4u.
First, I created whole structure writing only HTML code and then after finalising themes and design I wrote CSS. I used help from reddit when I was stuck.
It took me just 2 hours to make this simple website.
